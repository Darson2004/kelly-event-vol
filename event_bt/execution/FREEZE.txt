AMENDMENT A2 2026-09-01 (BETWEEN TICKS 1 and 2, researcher-approved).
  Two changes: a CORRECTNESS FIX and a new data source.

  (1) EXIT-STRIKE DEFECT (found while building the fills panel).
      cmd_build re-picked the ATM strike independently at exit, so 910 of
      967 events (94.1%) compared the straddle we BOUGHT against a
      freshly-struck ATM straddle at exit. A held straddle gains intrinsic
      value when spot moves; a re-struck ATM never does. The defect
      therefore destroyed the right tail -- precisely the trades that carry
      this strategy.
        gross_ret v2 (buggy) : mean -11.01%  median -10.60%  frac>=+50% 0.23%
        gross_ret v3 (fixed) : mean  +2.51%  median  -2.22%  frac>=+50% 4.61%
      engine.py -- the PRODUCTION backtest -- was always correct ("ATM
      strike fixed at entry", engine.py:345; exit marks use rec.strike), so
      the graduated +6.39%/trade is NOT affected. The defect was confined to
      this execution pack.
      Tick-1's EX-2 result is entry-only (cost_frac) and is UNAFFECTED; the
      17.7bp measurement in POLICY v1 stands.
      CONSEQUENCE: exit_mid is now lead-specific (3.69 distinct values per
      event; 99.3% of events have >1). ANOM-2 is INVALIDATED -- it was an
      artifact of the bug, not a property of the trade. EX-5 is a genuine
      experiment again and is returned to the alpha-spending queue.

  (2) WHY G1 DID NOT CATCH IT, and the fix.
      The tick-1 gross_ret assertion checked gross_ret ==
      (exit_mid-entry_mid)/entry_mid -- arithmetically TRUE while exit_mid
      came from the wrong contract. Self-consistent, economically wrong.
      Added an ECONOMIC-IDENTITY guard: exit_strike MUST equal strike.
      G1 now checks domain, degeneracy AND identity.

  (3) FILLS PANEL from the $52.65 OPRA tcbbo purchase.
      New command `fills` joins trade prints to the contracts we would have
      traded (OSI symbol construction), and computes the empirical PHI:
      volume-weighted |price - mid| / quoted half-spread.
      New semantic columns: phi_implied_entry, eff_half_frac_entry,
      frac_vol_at_mid_entry, frac_vol_inside_entry, exit_strike.

  selftest 11 -> 14 checks (added A2 regression: an exit on a different
  contract must FAIL semantics). Semantics 15/15 PASS on panel_fills.csv.
